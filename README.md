# Loss Visualizer

## 概要

購入前の迷っている瞬間に、不要な買い物によって失う選択肢や、見送ることで取り戻せる価値を見せる浪費防止アプリ。

## 目的

支出後に家計簿へ記録するのではなく、コンビニなどで買うか迷っている数十秒に介入し、衝動買いを思いとどまるきっかけを作る。

損失を見せるだけでユーザーを責めるのではなく、見送った直後に「今回はこれだけ取り戻せた」という達成感を与える。

## 着想

お金に余裕がなくても、コンビニでアイスなどの不要な物をつい買ってしまうことがある。一方、その場で思いとどまれれば、欲しさを長く引きずることは少ない。

そこで、例えば180円の買い物について、次のような情報を即座に見せる発想に至った。

- 180円で買える別のもの
- 今月の不要な買い物の累計
- 貯金目標までの残額
- 今回買うと目標がどれくらい遠のくか
- 今回見送った場合に積み上がる仮想貯金

## 想定ユーザー

- 収入や貯金に余裕はないが、小さな浪費を繰り返してしまう人
- コンビニ、ネット通販、ゲーム内課金などの購入前に迷う人
- 家計簿は続かないが、短い判断のきっかけなら使えそうな人

## MVP

最初は「お金の不要な買い物」に絞る。

1. 買おうとしている商品名と金額を入力する。
2. 貯金目標と目標金額を設定する。
3. 購入前に、累計浪費額・目標への影響・代替できる価値を表示する。
4. 「買う」または「今回は見送る」を選択する。
5. 見送った金額を仮想的な節約額として記録する。
6. 購入・見送りの履歴と、月間・累計の金額を表示する。
7. 目標達成状況をゲージや簡単なグラフで表示する。
8. データはまず端末内に保存する。

## 主要機能候補

- 購入前のクイック入力
- 買う／見送るの判断記録
- 貯金目標と残額表示
- 見送った金額の累計・月間集計
- 購入した不要品の振り返り
- 行動を変えたことで取り戻した価値の表示
- ホーム画面ウィジェット
- リマインダーや通知
- 将来的な時間・勉強・サブスクの損失可視化

## 非対象機能（MVPではやらない）

- 銀行口座・クレジットカードとの自動連携
- レシートの自動読み取り
- SNSやゲーム利用時間の自動監視
- 将来の年収や職業を断定する金額換算
- AIによる複雑な家計アドバイス
- アカウント登録やクラウド同期
- 他ユーザーとのランキング、SNS共有、コミュニティ
- 時間・勉強・健康管理を同時に扱うこと

## 強み

- 一般的な家計簿と違い、購入後ではなく購入直前に使う。
- 「失った額」だけでなく「見送って取り戻した価値」を表示できる。
- 端末内保存を中心にすれば、小さく安全に作り始められる。
- グラフ、通知、ウィジェット、課金などiPhoneアプリらしい機能を段階的に追加できる。
- 最初のApp Store公開で、SwiftUI、ローカル保存、テスト、課金、審査対応まで経験しやすい。

## 課題・注意点

- 損失を強調しすぎると、ユーザーが責められていると感じて継続しない可能性がある。
- 「損失」の意味が広がりすぎると、家計簿・習慣管理・時間管理アプリとの差がぼやける。
- 見送り額は実際の貯金ではないため、仮想的な節約額であることを明確にする。
- 将来の収入や機会費用は確定値として扱わず、ユーザー設定値や参考値として表示する。
- 入力が面倒だと購入直前の利用に間に合わない。数秒で操作できる導線が必要。
- 買うこと自体を悪とせず、必要な買い物や自分への適切な支出も尊重する。

## 収益化候補

- 無料版は登録できる項目数を限定し、無制限登録を買い切りで提供する。
- 詳細な分析、比較シナリオ、追加ウィジェットをプレミアム機能にする。
- PDF・画像レポート出力を有料化する。
- AIによる改善プラン生成は、利用コストを考慮して有料枠にする。
- 広告削除を買い切りで提供する。
- 継続利用率が確認できた後に、サブスクリプションを検討する。
