# デプロイ手順（Vercel）

Web版MVPをVercelへ公開するための手順と、公開前の確認事項をまとめる。

**2026-08-30時点で、まだ一度も公開していない。** 第10ループでは公開準備までを行い、実際のデプロイはユーザーの承認を得てから実施する。

## 前提

- デプロイ先は **Vercel**（第10ループでユーザーが決定）
- バックエンド・データベース・環境変数は使わない。ブラウザ内保存のみで動作する
- そのため、Vercel側で設定が必要なシークレットや環境変数は**ない**

## リポジトリ直下の `vercel.json`

```json
{
  "$schema": "https://openapi.vercel.sh/vercel.json",
  "framework": "vite",
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

### なぜ `rewrites` が必要か

このアプリはReact Routerを使うシングルページアプリケーション（SPA）で、`/history` や `/settings` は**サーバー上に実在するファイルではない**。ブラウザ内でJavaScriptが画面を切り替えているだけである。

そのため、設定がないまま静的ホスティングへ置くと、次のようになる。

- アプリを `/` から開いて画面内で移動する分には動く
- しかし `/history` を**直接開く**（ブックマーク、リロード、URL共有）と、サーバーがそのファイルを見つけられず**404になる**

`rewrites` は「実在するファイルが見つからなかったリクエストは、すべて `index.html` を返す」という指示である。これによりどのURLで直接開いてもアプリが起動し、React Routerが正しい画面を表示する。

Vercelのルーティングは「リダイレクト → ヘッダー → 実ファイル → rewrites」の順に評価されるため、`/assets/*.js` などの実在するファイルは先に見つかり、`index.html` には化けない。第10ループでこの順序をローカルで再現して確認済み。

### 既知の挙動

存在しないアセット（例：`/assets/typo.js`）へのリクエストも `index.html`（200）を返す。これは全パスを対象にしたSPAフォールバックの一般的な挙動で、Viteはハッシュ付きファイル名を `index.html` から参照するため、通常利用では発生しない。

## デプロイ手順

### 1. 事前確認

```bash
npm run typecheck   # 型エラー0件
npm run lint        # 指摘0件
npm test            # 全テスト成功
npm run build       # 警告0件
```

### 2. Vercel CLIのログイン状態を確認

```bash
vercel whoami
```

**未ログインの場合はブラウザ認証が必要で、これはユーザー本人が行う必要がある。**

```bash
vercel login
```

### 3. デプロイ

```bash
# プレビュー環境（本番URLには影響しない。まずこちらで確認することを推奨）
vercel

# 本番環境
vercel --prod
```

初回は、リポジトリのリンク先プロジェクトを対話的に尋ねられる。

## 公開後に必ず確認すること

第10ループの時点では実際のVercel環境で確認できていないため、**デプロイ後に以下を必ず確認する**。

- [ ] `/` が表示される
- [ ] **`/history` を直接開いて404にならない**（deep linkの最終確認）
- [ ] `/pending`、`/settings`、`/decide` も直接開ける
- [ ] リロードしても画面が保たれる
- [ ] スマートフォンの実機ブラウザ（iOS Safari）で表示崩れがない
- [ ] 判断を1件記録し、リロード後もデータが残る

## 補足

- データはすべて利用者のブラウザ内（localStorage）に保存される。サーバーには送られない
- そのため、公開してもユーザーのデータを預かることにはならない
- プライベートブラウジングなど保存できない環境では、アプリ内に警告バナーが表示される（第9ループで実装）
